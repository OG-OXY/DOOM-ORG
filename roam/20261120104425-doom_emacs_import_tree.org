#+title: Doom Emacs Import-Tree
#+filetags: :doom:emacs:import-tree:functions:elisp:lisp:directories:recursive:

* Explanation:
No---Emacs has no built-in =(require-directory ...)= function because =require= maps a single feature symbol (='foo=) to a single file (=foo.el=).

- /WHY =require= IS SINGLE-FILE:/ =require= checks the =features= list for a symbol provided by =(provide 'foo)= and loads the matching =.el= file from =load-path=.
- /WHAT YOU CAN DO INSTEAD:/ Loop over =directory-files= (or =directory-files-recursively=) and call =require= on the =intern=ed filename base of each =.el= file, or use Doom's =load!= across the file list.
- /WHAT TO WATCH OUT FOR:/ Every =.el= file in that folder must end with a matching =(provide 'filename-without-extension)= line, otherwise =require= will throw an error saying the feature was not provided.

* Solution:
*** Step-by-Step Guide to Requiring a Whole Directory
:PROPERTIES:
:CUSTOM_ID: step-by-step-guide-to-requiring-a-whole-directory
:END:
1. Add your directory (and subdirectories, if any) to =load-path= in =config.el=:

#+begin_src elisp
(let ((lisp-dir (expand-file-name "lisp" doom-user-dir)))
  (when (file-directory-p lisp-dir)
    (add-to-list 'load-path lisp-dir)
    (dolist (dir (directory-files-recursively lisp-dir "" t #'file-directory-p))
      (add-to-list 'load-path dir))))
#+end_src

2. [@2] Loop over all =.el= files in that directory tree and =require= each one by its base filename:

#+begin_src elisp
(let ((lisp-dir (expand-file-name "lisp" doom-user-dir)))
  (when (file-directory-p lisp-dir)
    (dolist (file (directory-files-recursively lisp-dir "\\.el\\'"))
      (unless (string-prefix-p "." (file-name-nondirectory file))
        (require (intern (file-name-base file)))))))
#+end_src

3. [@3] Ensure every =.el= file inside =lisp/= ends with =(provide '<exact-filename-without-el>)= (for example, =my-org-templates.el= ends with =(provide 'my-org-templates)=).
4. Rebuild/switch NixOS and restart =doom.service= from Fish, then verify all features loaded:

#+begin_src fish
systemctl --user restart doom.service
emacsclient --socket-name=doom -e '(list (featurep (quote my-org-functions)) (featurep (quote my-org-templates)))'
#+end_src

- /Verification:/ Fish prints =(t t)= and =systemctl --user is-active doom.service= prints =active=.
